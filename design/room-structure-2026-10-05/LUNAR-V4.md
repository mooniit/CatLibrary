# 月轨窗框、画框与墙角 v4

本文件记录 v4 历史样稿。[组合预览](lunar-assets-v4/scene-clean.png)、[三种实体空框](lunar-assets-v4/frame-templates-sheet.png)、[尺寸与锚点清单](lunar-assets-v4/manifest.json)。当前 [lunar.html](lunar.html) 使用 [v5](LUNAR-V5.md)：墙角收边已撤掉，侧框和窗台已细化，加入独立昼夜月色。

本轮保留已认可的 v3 墙面、地板、地毯和家具，只重做窗户与画框并添加窄圆角墙角收边。以上保留素材的 SVG、PNG 与 v3 逐字节一致。没有生成新的房间图或窗框、画框贴图。房屋仍采用 `room-standard-v1`；标准文件、相机、墙高、地板、五个基准点均未改动。

## 实体构造与同一套风格

窗框和画框均由 [lunar-joinery.mjs](lunar-joinery.mjs) 的实体网格构造，而非在平面矩形上装饰一张图片。圆润奶油漆面、细金属包边与少量月牙/星饰呼应书柜、桌椅的形态。材质依靠曲面法线、截面分层和微弱渐变表现，不添加投射阴影。

- 窗户：带倒角的左右侧柱、浅拱实体窗楣、浮雕月牙与两颗星、四个圆润角帽、金色圆截面边珠、实体中央窗梃及端部套环、圆角实体窗台。两个开口保持空白。
- 画框：带真实侧面和倒角的框条、浅拱框楣、带星饰的角帽、凸起月牙、金色边珠、底部星轨和窄深蓝内嵌条。画芯放在框体后方的凹槽里，保留原作比例，不裁切。空框输出无任何位图。
- 墙角：原后角内增加半径 `0.009L = 0.072 格` 的四分之一圆收边。高度等于固定墙高。曲面朝向带来窄幅明暗过渡，区分两堵墙；原墙面纹理、外轮廓与结构坐标不变。

实体框体法向范围为 `[-0.004, 0.022]L`，总深 `0.026L = 0.208 格`。主月牙为实际凸起的倒角实体，厚 `0.0038L`。金色包边为有圆截面的细管，细节不依赖屏幕描线。

## 三种尺寸模板与挂位

| 模板 | 外尺寸（格） | 外尺寸（L） |
|---|---|---|
| 横版 | 1.6 × 1.2 | 0.20 × 0.15 |
| 竖版 | 1.2 × 1.6 | 0.15 × 0.20 |
| 正方形 | 1.4 × 1.4 | 0.175 × 0.175 |

模板仅决定外尺寸。三种规格共用相同框条截面、角帽、月牙和星饰，按宽高调整框条长度及装饰位置；没有拉伸一张框图。每种均提供透明正面参考图、左墙投影与右墙投影。换画时使用 `wallArtwork(slot, template, artwork)`，只替换画芯。内开口参数由模型提供，画芯等比居中 contain；空白部分为奶油衬垫。

四个挂位中心仍为沿每墙 `1.44、6.56 格`、高度 `4.05 格`，三种框的中心不随尺寸切换移动。挂位与最大尺寸沿用上一轮已确认的放大范围。本轮没有改变家具占格、接地锚点、任何挂位或窗户位置。

窗户宽 `2.56 格`、高 `1.7 格`、下沿 `3.2 格`、中心 `4.05 格`。窗台宽 `2.72 格`、深 `0.368 格`、厚 `0.064 格`，底部 `3.136 格`；距 3 格高书柜顶仍为 `0.136 格`。实体构件均包含在原窗框和窗台的包络内。

右窗直接镜像同一左窗模型的投影；右窗 PNG 是左窗 RGBA 像素的直接反序复制，像素差为零。五类家具继续使用先前确认的精确镜像素材。两墙的画框由同一实体模型交换 X/Y 轴并修正面朝向，造型、部件与尺寸完全一致。

家具的尺寸、占格、两方向和接地锚点见 [v2 尺寸表](LUNAR-V2.md#家具尺寸占格与接地锚点)，所有当前素材的像素裁切框、地面锚点、挂位中心和构件列表见 [manifest.json](lunar-assets-v4/manifest.json)。

## 素材与复用规则

`lunar-assets-v4/` 包含 32 组透明 SVG/PNG：10 件家具方向、6 个墙/地面材质、2 个窗户、3 个正面空框、6 个墙面空框、4 个套画素材、1 个墙角收边。原始家具母版和已确认的墙/地板母版仍保留。旧的窗框、画框绘制母版只保存在 v3 历史目录，当前版本不引用。

1. 以 `joineryModel(w,h,kind)` 生成共享实体构造，所有坐标单位为固定房屋边长 L。不要用图片切片改变框条比例。
2. 用 `mountJoinery` 挂到标准墙面；窗台另由 `windowModel` 生成，采用同一投影与圆角截面。
3. 通过固定相机的网格排序生成 SVG，再导出 PNG。透明裁切余量至少 3 像素；保留 manifest 的 viewBox 和锚点。
4. 画芯是独立的一份平面原画，凹入框体后方。框体是实体表面，画芯不得替代框体，不随框尺寸变形。
5. 墙角收边作为独立 `corner-transition` 素材置于墙面前方；不改房屋标准或家具占格。
6. 屏幕只等比缩放整屋。家具依照 `project(worldGroundAnchor) - pixelGroundOrigin` 接地；墙饰采用清单中的 `worldMountCenter` 定位。


## 验证

18 项几何测试通过，覆盖固定标准、完整占格、模型包络、实际框厚与浮雕厚度、窗台净距、左右挂载一致性和墙角范围。浏览器检查全部 32 种家具朝向组合、四挂位 × 三模板 × 三画芯选项、显隐、360/390px 显示及原画比例，无错误和越界。

透明审计检查全部 32 张 PNG 的裁切边缘，10 个家具方向没有游离残留像素且位于声明投影包络内。五组家具与两窗的镜像像素差均为零；空画框和窗框的 SVG 不含位图，画芯仅一份。墙体、地板、地毯和家具输出与 v3 一致。
