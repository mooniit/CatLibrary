# 房间结构固定标准 v1

日期：2026-10-05。以首轮“结构与占格”冻结唯一比例 `room-standard-v1`。墙高 1.5 倍、8×8 网格、中央 6×6 地毯和三格书柜保持；窗画整体下移 0.95 格。本页说明固定结构校准预览；当前应用已接入同一标准下的月轨 v5，见 [定稿设计](LUNAR-V5.md) 与 [原生接入](../../docs/plans/room-redesign-2026-10-05/NATIVE-LUNAR.md)。

## 已实现

- 三张参考图分别记录采样原点和比例，共用加权拟合的地面方向。可切换原图与叠线；遮挡下的原点和地板前角明确标为推算。
- 固定平行投影，无近大远小和相机拖动。原点在后侧墙脚；+X 朝右墙开口，+Y 朝左墙开口，+Z 向上。
- 墙高固定为参考图 1.5 倍；相机、视图、墙厚与地台厚全部使用只读标准，移除墙高切换，地板和投影方向不变。
- 正式选定 8×8 网格；原 6/8/10 比较已改为 8×8 下的家具居中示例。
- 书柜、书桌、椅子、猫爬架、猫窝结构实体，脚底/底座统一落在 Z=0，窗框和画框具备实体厚度。每件可切换 +X/+Y；方向切换通过实体构造完成。
- L 形三格的两个朝向示例；缺角不占格。
- 书柜三格；左右窗位均在各自墙面中点，宽 0.32L、高 1.7 格，下沿 3.2 格。窗台底部与书柜顶面净距 0.136 格。四个画位随窗整体下移，中心高均为 4.05 格。窗位为真实开口，暂不设置窗外景色；隐藏窗户后恢复完整墙面。
- 地毯固定覆盖中央 6×6 格，四周各留一格，允许家具摆在其上；可关闭显示。

本轮代表家具已改为整数格锚点与明确的矩形占格，水平外缘中心和占格矩形中心重合；切换朝向时旋转占格和实体后重新居中。后续布置阶段将增加拖动吸附和确认流程。L 形示例仍严格只占三个格子。

| 物件 | +X/+Y 默认方向 | 默认占格 | 锚点（从 0 开始） |
|---|---|---|---|
| 书柜 | +X | 1×3 | (0,1) |
| 书桌 | +Y | 3×2 | (4,2) |
| 椅子 | +Y | 1×1 | (5,1) |
| 猫爬架 | +X | 2×2 | (0,5) |
| 猫窝 | +Y | 2×2 | (5,6) |

占格是本轮结构物件的示例规格，不要求后续同类别采用相同格数。矩形转向后行列互换，以同一格锚点重新定位，实体尺寸不变。这里的“居中”指 X/Y 世界平面居中，不是把整张立体图的屏幕包围盒居中。

## 已冻结坐标参数

房间物理底面为 1×1，SVG 宽度为 1080。

```text
X_screen = 540 + 480 (x − y)
Y_screen = 537.471698 + 239.576665 (x + y) − 588.222783 z
固定墙高 = 0.8083190784267942 L
固定视图 = 1080 × 1073；地板内角宽 = 960
```

地面边线角度约 ±26.52°；若采用对称正交、三轴统一尺度的约束，相机俯视约 29.94°。这是约束下的推导，不代表从截图唯一恢复了原游戏相机。

`room-standard.mjs` 是预览的唯一房屋几何来源，`room-standard-v1.json` 是完全同值的跨工具导出。`calibration.json` 仅解释历史采样与校准来源，不再实时驱动房屋比例。几何回归检查已确认的五个角点，修改采样或家具不会自动重算相机。

调整后的挂位坐标见预览表格，采用物理边长 L/8 作为高度单位。窗下沿 3.2 格，窗高 1.7 格；画位高 1 格，与窗中心等高。地毯范围 X/Y 均为 0.125…0.875（1…7 格），圆角半径 0.02L。房屋比例与挂位坐标分开管理，移动挂位不修改房屋标准。

## 下一确认点

后续所有家具在此标准模板内制作两个方向，房屋仍由固定几何绘制，不再以整屋生成图重建房间。继续阶段 B 的拖动、吸附、确认和数量限制时也继承同一标准。
