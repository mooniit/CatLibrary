# 月轨家具样稿 v1

历史结构样稿。当前预览与最终素材已切换为 [月轨 v2](LUNAR-V2.md)：根据用户最新指示直接镜像母版，并采用三种放大的通用画框。下文记录 v1 当时的制作规则。

2026-10-05。打开 [组合预览](lunar.html)。本轮是具体家具与装饰的独立美术样稿，使用原生 SVG 曲面和结构绘制，未接入生产主页。

## 固定房屋与位置

唯一几何来源仍为 `room-standard-v1`，继承 `room-standard.mjs` 与 `geometry.mjs`。房屋标准、JSON、两张固定锚点、家具尺寸/格锚点/占格、窗位和画位均未修改。现有结构页只增加了样稿链接。历史整屋稿只参考曲线、软垫和配色，不参与房屋几何计算。

相机画布 1080×1073；地板宽 960；地面真实正方形；8×8 方格；墙高 0.8083190784267942L（6.46655 格）。固定平行投影，不发生近大远小。中央地毯仍为 `[1,1]` 开始的 6×6，家具可叠在其上。

## 设计内容

- **书柜**：奶油色侧板、深蓝内背板、三层书架；浅拱顶上的单个月牙徽记，少量金色直线。书籍高低变化和细窄书脊线提供细节，侧板/层板/内腔都有真实深度。
- **书桌**：厚圆角桌板、深蓝嵌入桌垫、薄金色收边；四根微弯收细桌腿配金色脚套，前裙板一枚月牙。
- **椅子**：朝前开放的曲面包裹椅背，两侧扶手向前降低；深蓝软垫和克制的绗缝、金色脚套。
- **开放猫窝**：椭圆奶油色底座、深蓝软垫；前沿约 0.216 格，后沿最高 0.68 格，软垫顶部约 0.344 格。前方开口低于软垫，使后续躺卧的猫尽量可见。
- **猫爬架**：圆角软垫底座、两根浅色绕绳柱、偏置中层平台、向房内开放的上层月牙托座。金色轨线连接高柱与中层平台，平台的轴向与底座一致。
- **窗户**：两堵墙各一款独立投影，厚奶油窗框、细金色内缘、单竖梃和小月牙；窗外留空。沿用窗框深度 0.026L、窗台深度 0.046L、窗台厚 0.008L。
- **墙饰**：靠后两位使用“猫爪星空”，靠前两位使用“戴珍珠耳环的猫”。原图比例分别为 1424:1104、1191:1320；在固定挂位内 contain 装框，未裁切。框深 0.026L，前缘在墙内 0.022L，另有内衬与画芯深度。
- **墙壁**：奶油色抹灰，低踢脚线与单条金色边线，无密集壁纸花纹。
- **地板**：浅暖木，沿固定世界轴的细板缝与交错接缝；板缝是材质细节，布置网格另行显示。
- **地毯**：深蓝圆角中央 6×6，双细金边、中央月牙、两条星轨和三个节点。不可移动，可隐藏。

主要色：奶油 `#f4e9d3`，象牙 `#fff7e8`，深蓝 `#233c60`，软垫蓝 `#36557b`，哑光金 `#c6a05e`。用结构表面方向的固定色阶表达体积，没有投射阴影或场景光源。

## 地面家具规格

单位：格，1 格 = L/8；编号从 0 开始。格锚点为占格最小 X/Y。接地点为完整水平外轮廓最小 X/Y，Z=0。尺寸含全部壳体和装饰，不只统计支脚。

|---|---|---|---|---|---|
| 书柜 | +X | 0.96×2.08×3 | 1×3 | [0,1] | 0.02,1.46,0 |
| 书柜 | +Y | 2.08×0.96×3 | 3×1 | [0,1] | 0.46,1.02,0 |
| 书桌 | +X | 1.36×2.40×1.44 | 2×3 | [4,2] | 4.32,2.30,0 |
| 书桌 | +Y | 2.40×1.36×1.44 | 3×2 | [4,2] | 4.30,2.32,0 |

| 椅子 | +Y | 0.96×0.92×1.60 | 1×1 | [5,1] | 5.02,1.04,0 |

## 墙面挂位与锚点

左右墙分别为 X=0 与 Y=0。两窗水平中心为 4 格，窗体宽 2.56 格、高 1.7 格；下沿 3.2 格、中心高 4.05 格。窗台底 3.136 格，到书柜顶净距 0.136 格。

每堵墙的画位水平中心分别为 1.44 与 6.56 格，挂位范围 1.28×1 格；中心同为 4.05 格。画框按原幅在此范围内居中，所以实际外框下沿随画幅不同，挂位和挂心没有变化。所有窗画素材记录 `worldMountCenter` 和 `slotId`。

## 独立素材与复用方法

`lunar-assets/` 含 20 个透明 SVG 母版及对应 RGBA PNG：五类家具各两个朝向、窗户左右、两幅画各左右、墙材左右、地板、地毯。墙材是按标准墙面尺寸导出的可独立层，窗洞开口保持。画作在 SVG 内嵌原图，方便独立复用。

- [manifest.json](lunar-assets/manifest.json)：尺寸、完整格子列表、格锚点、世界接地点、裁切 viewBox、像素接地锚点、墙面挂心和配色。
- [scene-clean.png](lunar-assets/scene-clean.png)、[scene-grid.png](lunar-assets/scene-grid.png)：同房屋组合与占格版本。
- [scene-alternate.png](lunar-assets/scene-alternate.png)：全部家具切换到另一朝向。
- [edge-contact-sheet.png](lunar-assets/edge-contact-sheet.png)：十个地面家具方向在浅底/深底的透明边缘检查。
- [lunar-art.mjs](lunar-art.mjs)：可复用几何母版与材质规则。

制作顺序：读取标准 → 依据单品宽/深/高构建局部 u/v/z 结构 → 局部正面统一 +u → +X 映射为 `[x+u,y+v,z]`，+Y 映射为 `[x+width-v,y+u,z]` → 每个方向分别投影与裁切 → 保存锚点。两方向具有正确的侧面、开口、层架深度和左右关系，没有旋转/镜像已经绘好的图片。

实际预览加载独立的家具 SVG，合成到同一个由标准绘制的房屋中。摆放公式：

```text
spriteTopLeft = project(worldGroundAnchor) - pixelGroundOrigin
spriteSize = viewBox.width × viewBox.height
```

PNG 与 SVG 使用相同原生画布和裁切尺寸。`pixelGroundOrigin` 可以位于图片外，因为它是局部世界原点的投影，并非图片底边中心；不要自动改为底边中心。裁切保留 6 像素透明余量，禁止以随机 alpha bbox 重裁后丢失锚点。对整个房间执行一次等比缩放。

曲面用分段结构与固定表面色绘制；可见面按平面分割排序，金线与图芯一起参与遮挡。曲面接缝使用同色覆盖消除透明栅格裂缝，外缘保留透明。不要给整件素材加投射阴影、滤镜光晕或依赖房屋光照的明暗。

重新制作与验证（从项目根目录运行，使用现有 Node、Python/Pillow、Playwright 与 Edge）：

```powershell

node --test design/room-structure-2026-10-05/geometry.test.mjs design/room-structure-2026-10-05/lunar.test.mjs
# 先启动项目自带 serve.py，或复用已在 4181 运行的服务
node design/room-structure-2026-10-05/lunar-browser.test.cjs
python design/room-structure-2026-10-05/audit-lunar-alpha.py
```

几何检查覆盖所有真实曲面顶点与线条的完整外轮廓、居中和 Z=0 接地；32 种朝向组合的占格互斥；两方向独立投影；猫窝低沿；画幅与窗台净距；像素锚点回算。浏览器检查通过真实控件切换全部组合，检查标准相机、独立素材加载、显隐、360/390 px 和控制台/资源错误。透明检查读取 PNG alpha，检查透明裁切余量与家具连通域，结合浅深底色目检确认边缘。

验证数据保存在 [verification.json](lunar-assets/verification.json) 与 [alpha-verification.json](lunar-assets/alpha-verification.json)。房屋标准文件与固定提交 `cc33751` 的差异为空。
