# 房间与家具坐标约定

画板为 1000 × 1250，地面为 10 × 10。所有款式共用固定槽位；图集像素坐标只用于确定家具真实支点，不参与决定家具摆放位置。

投影：`X = 500 + 44.5 × (x − y)`，`Y = 560 + 30 × (x + y)`。两组地面平行线斜率为 ±30/44.5；竖直边始终保持竖直。墙高 490。

| 基准点 | 画板坐标 |
| --- | --- |
| 后墙角 / 地面原点 | (500, 560) |
| 左地板角 | (55, 860) |
| 右地板角 | (945, 860) |
| 前地板尖角 | (500, 1160) |
| 后墙顶角 | (500, 70) |
| 左 / 右墙顶端 | (55, 370) / (945, 370) |

墙厚向室外展开：左右各 18，向上 12，后顶外角为 (500,46)。顶面与竖向切面独立绘制；地台厚 26，前端仍为尖角。墙与地板图只提供材质，由原生 Canvas 投影到上述几何面，不能用生成图的轮廓替代坐标。

每张家具素材记录源区域、真实锚点、两组水平边斜率和可见支点。渲染用竖向缩放和剪切将两组边统一到地面斜率；商店缩略图使用同一变换。阴影依据支点绘制，随单件隐藏。第二套桌椅在图集中相邻：书桌额外排除 (787,580)—(826,614)，椅子额外排除 (660,577)—(750,606)，避免带入邻件像素；所有真实支点均在排除区域之外。

素材：原木奶油图集 1254 × 1254；胡桃鼠尾草新版图集 1536 × 1024。新版包含叶形窗帘杆、爪印椅垫、绿植书柜、藤编猫窝、月牙抽屉把手与羽毛笔。奶油抹灰、鼠尾草护墙、雾蓝壁纸共用墙体轮廓，只替换材质。猫咪暂不绘制，领养数据与管理功能仍保留。

配置按既有本机身份保存。已有款式与隐藏状态继续沿用；尚未保存的交互预览默认第二套家具及鼠尾草墙面。
