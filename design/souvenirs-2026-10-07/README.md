# 六地旅行纪念品

**2026-10-07 最新状态：用户否定本批简单色块造型，要求六件精细重制，并将卢浮宫改为维纳斯雕像。[v2 候选稿](v2/README.md) 尚未通过真实边线门槛；下述数值模型只用于既有业务验证，不能作为最新美术验收通过证据。**

2026-10-07 用户确认六种 1×1 小雕塑：故宫宫殿、卢浮宫玻璃金字塔、富士山、埃及金字塔、埃菲尔铁塔、自由女神像。属于旅行奖励，不列入购买目录，不受商店每款 1 件购买额度影响；每只猫每地仅一件。

本批用数值模型直接绘制，没有调用图像生成工具，也没有生成图角度修正、斜切、拉伸或自动寻接地点。完整数值面、尺寸、锚点和占格在 [models.json](models.json)，构建入口为 `scripts/build-souvenir-models.mjs`，引用房屋唯一 `room-standard.mjs` 与 `geometry.mjs`；相机、网格、房屋尺寸未改。每件坐标样板为同名 `*-coordinate-guide.svg`，原生 PNG 样板见同名 PNG。

共同尺寸：宽深 0.10L，水平外缘居中在 0.125L 单格内，锚点 (0,0)，最底点 Z=0；高度依次为 0.115、0.10、0.09、0.115、0.22、0.21L。已有家具占格不变。

实际绘制与注册同用模型面，不用只检查包络。`test/souvenir_render_test.dart` 检查每件真实底座两条 alpha≥50% 的边，角度误差小于 1°、位置误差小于 2 像素；检查全部顶点、接地、透明边缘、两朝向及组合。第一朝向按固定数值投影栅格化；第二朝向直接镜像第一图，RGBA 每个像素完全一致。原生渲染器缓存小尺寸透明图，不重复生成第二朝向。

原生组合图：[六种纪念品在固定房屋中](../../docs/evidence/m6-souvenirs-room.png)。验证日志：[像素检查](../../docs/evidence/m6-souvenir-render.txt)。正式旅行照片插画 12 张按用户确认留到 M7，相册记录不冒充照片素材。
