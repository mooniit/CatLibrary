六款：故宫宫殿、卢浮宫维纳斯雕像、富士山、埃及金字塔、埃菲尔铁塔、自由女神像。2026-10-07 用户要求提高精细度、地标特征与项目画风一致性，并将卢浮宫的玻璃金字塔改为维纳斯。

**当前为未通过几何接入门槛的设计稿，不是生产素材。** built-in imagegen 生成，仅第一朝向；没有自行用程序编辑原图，也没有拉伸/斜切。正式第二朝向必须在第一朝向通过后逐像素镜像。维纳斯原作裸身版本被生成工具拒绝，采用古典披衣的断臂形象；用户已明确确认“采用当前披衣版本”。

- `*-coordinate-guide.svg/.png/.json`：数值结构、完整尺寸、固定投影与注册原点。
- `*-coordinate-guide-axes.png`：真实底座上下两组 X/Y 结构边。
- `*-x-source.png`：当前选用的精细候选原图；原工具输出仍保留在默认 generated_images 目录。
- `*-actual-prompt.txt`：当前原图的实际完整生成提示词；输入为该款的 axes 样板，使用 built-in 工具、透明背景。
- `*-registration.json` / `verification.json`：实际素材边线测量结果，包含比例、角度、位置、样本数量及通过状态，失败不输出应用资源。

六款宽深均 0.10L，1×1 占格，锚点 [0,0]，全水平轮廓居中于 X/Y=[0.0125,0.1125]L。故宫高0.115L、维纳斯0.21L、富士山0.09L、埃及金字塔0.115L、铁塔0.22L、自由女神像0.21L。维纳斯相对被替换的玻璃金字塔从0.10L改为竖向0.21L；没有修改房屋或占格。该变化尚未应用到数据库目录。

重建样板：`node scripts/build-souvenir-v2-guides.mjs`。生成提示词基线：`node scripts/souvenir-v2-prompts.mjs`。测量注册：`node scripts/register-souvenir-v2.mjs`；当前命令返回失败，不能据此宣告素材已通过。仅等比缩放与样板轮廓中心平移，复用已有 `register-source.mjs`，没有放宽 1°、外缘2px或3.5%比例门槛。
