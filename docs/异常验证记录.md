## 2026-10-09 首页云端同步

使用原生模拟器 `emulator-5554`，复用上一批两个独立云端匿名成员及其家庭；各客户端独立内存 SQLite、模拟 preferences。没有新注册、购买、赠送、补结算或原账户迁移。对方按正常编辑权与版本规则移动一幅已有画作并保存，每轮布局版本增加一次，三轮版本由 2 到 5；库存两件、双方余额 0 保持不变。

| 情况 | 实际结果 | 范围 |
|---|---|---|
| 对方保存后自动发现更新 | 最终轮远端保存后 23812ms 出现提示；未手动调用检查函数，使用原有 30 秒定时器 | 一台模拟器内两个云端客户端 |
| 更新提示出现 | 显示布局仍为旧版本，点击刷新后获取新版本；同一房间场景实例保留 | 真实 RPC 与首页 UI |
| 断网读取失败 | 已确认布局保留，显示离线、猫咪与布局重试提示 | HTTP 适配器拒绝请求，未切断物理网络 |
| 点击重试 | 新成功响应使连接状态恢复，布局保持；双方余额直接核对仍为 0 | 真实云端 RPC |
| 重新进入首页 | 重建 HomePage，读取最新版本 5；配置、场景素材就绪后截图显示正确布局与已连接 | 首页重建，未冷重启整个生产应用 |
| 原身份保护 | 原模拟器三个私有文件哈希一致，普通 0.1.17+18 APK 覆盖恢复，包哈希未变 | 原账户未迁移，物理手机未操作 |

最终原生测试通过，静态分析无问题。结果为 [业务报告](evidence/m7-home-sync-native.json)、[账号保留](evidence/m7-home-sync-preservation.json)；三图为 [自动提示](evidence/m7-home-natural-update.png)、[断网保留](evidence/m7-home-offline-retained.png)、[重新进入](evidence/m7-home-reentered.png)。生产代码本轮未修改，既有全量 141 项 Flutter 测试结果沿用上一批，不把原生新增测试计入该数量。

## 2026-10-09 本地业务并发

运行 `node scripts/test-business-contention.cjs`。固定目标为本地 `supabase_db_CatLibrary`，不接受云端配置或设备会话。脚本新建五个随机家庭、六个合成身份，保留私有 fixture；测试日期和初始余额明确隔离，不作为正式经济规则。协调连接先持有家庭或钱包行锁；逐个启动独立业务连接，并用 `pg_stat_activity.wait_event_type='Lock'` 核对两个连接均在等待后才释放屏障。由等待顺序覆盖两种竞争先后，避免把普通 Promise 并发误当成数据库实际重叠。

| 竞争场景 | 结果 |
|---|---|
| 奖励读取先等待、零点结算随后等待 | -10 合成余额获得 5 分钟应得 10 币，利息基数 0、利息 0、猫费 20，最终 -20；仅一条奖励、一条猫费及一次家庭日期结算 |
| 零点结算先等待、奖励读取随后等待 | 同样最终 -20，证明结算内先核算奖励；重复结算返回已执行，完整测试快照不变 |
| 两位成员同时读取已达标修缮 | 各一小时的持久检查点合计 7200000ms；仅一次完成，后一成员读到已完成后的免缴状态；一个窗口、完成时间不变，原两条修缮计时均不发币 |
| 购买先等待、自动费用随后等待 | 正式 30 币画作购买成功、发放一件、扣款一条；随后自动猫费 20，使余额为 -20，符合自动费用可欠款规则 |
| 自动费用先等待、购买随后等待 | 先扣 20，余额 10；30 币画作购买拒绝且没有库存或购买流水；原请求重试结果不变 |

五组通过，实际结果为 [本地并发报告](evidence/m8-business-contention.json)。只使用当前正式商品，不修改目录/价格；购买成功与失败均再次重试原请求，核对库存、流水、余额和结算记录未多增。原家庭余额记录、流水条数、库存与布局前后摘要相同，未执行原家庭结算；五个测试家庭不删除。没有修改生产函数、客户端或货币规则。

范围为本地 PostgreSQL 多连接及真实业务函数；奖励场景的计时证据在竞争开始前已持久化，修缮场景的两条检查点也已持久化，未据此证明双设备同时上传过程。未模拟真实北京时间零点、实际两小时计时或远程 cron 调度；本地顺序/锁结果不能替代云端、模拟器或真机联合验收。
