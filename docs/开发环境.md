## 运行

在项目根目录执行：

```powershell
./scripts/flutter.ps1 pub get
./scripts/flutter.ps1 doctor -v
./scripts/flutter.ps1 devices
./scripts/flutter.ps1 test
./scripts/flutter.ps1 analyze
./scripts/flutter.ps1 build apk --debug
./scripts/flutter.ps1 run -d <实际 Android 设备编号>
```

初次运行安装的 SDK 可能需下载依赖；.tooling 不进入 Git。Android 手机连接 USB 后需在手机上允许此电脑调试。iOS 工程必须在 Mac 上打开，Windows 不执行 iOS 构建。

本地后端：

```powershell
./.tooling/supabase-cli/node_modules/.bin/supabase.cmd start
./.tooling/supabase-cli/node_modules/.bin/supabase.cmd test db
./scripts/probe-cloud.ps1
```

实际验证状态与证据见 [M0 记录](M0-实施与验证记录.md)。

## 首次下载的网络处理

Gradle 9.3.1 使用官方 binary-only 分发，SHA-256 为 b266d5ff6b90eada6dc3b20cb090e3731302e553a27c5d3e4df1f0d76beaff06，来源为 [Gradle 官方校验列表](https://gradle.org/release-checksums/)。原下载端点 TLS 中断后，改从 Gradle 官方 GitHub 发布资产取得同一文件并校验；没有关闭证书校验。

本机已启用系统代理，Gradle 不自动沿用 Windows 系统代理；本轮在忽略目录 .tooling/gradle-cache/gradle.properties 配置其地址。换电脑需按本机网络重新配置，不复制凭据。SDK/Pub/Gradle 均为项目内缓存，脚本不永久修改系统 PATH。

Web 预览使用 `build web --no-web-resources-cdn`，避免 CanvasKit 运行时依赖 CDN；中文字体回退仍可能请求字体服务，不承诺浏览器完全离线。浏览器预览的计时数据只保留内存。
