# 原生视觉测试与账号保留

已有账号的设备不能使用默认 `flutter drive`。本地 Flutter SDK 的 `FlutterDriverService.stop()` 会在测试结束时卸载它安装的应用；Android 安装服务也可能在覆盖安装失败时退回卸载重装。

2026-10-08 的相册测试触发了这个默认清理行为，模拟器身份缓存被删除。已保留测试前 SQLite 快照及故障记录，用原账号已有刷新会话恢复原身份与 SQLite；服务端原钱包未变，误建身份的本地文件已单独保留。正常包启动后核对原会话、SQLite 所有者及钱包一致。手机未被操作。证据见 `../evidence/m7-album-account-recovery.json` 和 `m7-album-identity-restored.json`，不能将这次恢复写成全程未丢失数据。

## 使用方式

仅在明确选定的模拟器运行，测试入口必须使用内存数据库及只读模拟数据。先用 `scripts/build-phone.ps1` 生成普通 APK，保留独立文件；不要把测试入口构建到该普通包路径。

```powershell
$env:ANDROID_ADB_SERVER_PORT = '15037'
node scripts/run-native-ui.cjs `
  --serial emulator-5554 `
  --target integration_test/m7_album_ui_test.dart `
  --driver test_driver/m7_album_driver.dart `
  --restore-apk build/app/outputs/flutter-apk/catlibrary-lunar-native-debug.apk
```

脚本先停止应用，将已有 SQLite（含保留副本）与偏好文件备份到忽略的 `.tooling/native-ui-backup-*`。Flutter 只构建 APK，ADB 明确 `install -r -t`；安装失败即停止，禁止卸载兜底。启动后按当前进程日志获取 VM 地址并转发到本机，驱动必须使用 `--use-existing-app` 与 `--keep-app-running`。日志中 VM 会话地址脱敏，不打印账号或会话。

结束后停止测试应用，逐文件核对原数据哈希。若不一致，保留备份并停止，不能自动覆盖或制造成功记录；一致后由 ADB 覆盖恢复普通 APK 并启动。APK 自带的 Flutter 内核和资源时间戳会随构建变化，属于运行时资源，不作为账号文件。这个入口拒绝物理手机与网络设备。

## 实际验证

10 项 Node 回归通过；模拟器相册完整运行通过，原 SQLite、保留的 SQLite 副本及偏好文件共 3 个文件哈希一致，普通包已恢复。正常启动后的原会话、SQLite 身份和钱包再次核对一致。记录见 `../evidence/m7-album-safe-native.txt`、`m7-album-safe-preservation.json`。这不替代远程业务、手机或总体性能验收。
