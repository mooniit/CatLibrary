# 月轨 v5 原生应用接入

版本：0.1.6+7。首页默认使用定稿设计；功能菜单 → 商店可调整显隐、朝向、画作及画框模板。

## 实际接入

- `LunarRoom` 在现有 Flame Canvas 上组合独立图层；不是 WebView，也不是整屋截图。
- 书柜、桌椅、开放猫窝、猫爬架、中央 6×6 地毯、两扇窗户、四个挂画位使用 `room-standard-v1` 的固定相机和坐标。图层按素材锚点放置，整间房统一等比缩放。
- 五种地面家具可选择 +X/+Y 朝向。占格沿用 `geometry.mjs`，不新增移动或库存系统。
- 两扇窗户可独立隐藏。隐藏后使用同一几何下的完整墙面，不留下天空或窗洞。
- 窗外随应用「白色简约／暗色夜晚」切换日间淡月和夜间星月。两边取景来自同一天空母版的不同局部，月相和画面内容不镜像。
- 横版、竖版、正方形画框为独立透明构件，画芯按原比例放入凹槽，不裁切。默认样稿搭配为后侧横版猫爪星空、前侧竖版珍珠猫；选择其他画作后套入所选模板。
- 两堵墙由母版纹理分别投影导出，没有镜像成品墙面；未加入已被撤销的墙角圆角收边。
- 已删除旧 10×10 坐标、旧渲染、旧家具图集、旧墙地素材、月牙罩及相关兼容切换。任何用户配置均只使用当前固定标准和 v5 构件，没有旧房屋备用路径。

## 素材与复用

`assets/images/room/lunar-v5/catalog.json` 包含可移植标准、挂位、双朝向占格及图层矩形。`scripts/export-lunar-runtime.mjs` 从已确认 v5 素材复制独立构件，并分别绘制四种开窗／闭窗墙面；不重新生成家具或整屋图。

家具继续使用用户确认的精确水平镜像第二朝向。窗景与画芯在应用内按实际窗洞／画框开口绘制，保留各自的内容方向。

保存沿用按用户隔离的 `room_furniture_v1_*` 键，包含 `facing-*`、`frame-template`、`window-left/right` 条目。读取既有记录时只保留显隐、画作及有效朝向和模板，旧款式不能恢复旧房屋；后续保存不再写入旧款式或月牙罩。覆盖安装保留数据库和身份。

## 完整手机构建

使用 `powershell -File scripts/build-phone.ps1`，从忽略的 `.tooling/local-phone-defines.json` 加载原手机服务配置。脚本在 URL 或 anon key 缺失时直接失败，避免误装没有真实钱包、任务板和自习页的交互预览版。服务密钥不提交到 Git。

当前本地服务地址为设备端 `http://127.0.0.1:54321`；需要本机 Supabase 服务运行，并对目标设备执行 `adb -s <serial> reverse tcp:54321 tcp:54321`。构建后的任务板、自习、身份、主题设置源码与固定标准提交 `cc33751` 一致。
