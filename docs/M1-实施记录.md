## 本轮交付：T05 页面接入与 T06 自动身份、初始钱包

- 普通启动自动复用本机 Supabase 会话；没有会话时匿名建立身份，无注册登录页。
- 调用 bootstrap_identity，由服务端根据 auth.uid() 原子建立个人钱包和初始赠送流水。初始为 30 喵喵币、0 鹰镑、0 宝石，重复、并发请求不重复赠送，不重置已有余额。
- 钱包及流水启用 RLS；客户端只能读取本人的数据，不能直接增删改余额或流水。RPC 不接收用户编号，避免替他人初始化/操作。
- 首次连接展示等待页；失败提供重试，成功进入默认猫窝并展示后端余额。开发预览为显式入口，标注无真实资产，不把预览余额当成成功。
- 保留四个导航、猫窝内商店/相册/设置及阅读占位。计时奖励、家庭、领养仍未正式接入；现有领养样例仍标注为内存试用。

## 运行

1. 启动本地 Supabase，执行 `supabase migration up --local` 应用增量迁移，不重置数据库。
2. 本机已有忽略配置 .tooling/local-phone-defines.json，只包含本地 URL 和 anon 公钥。
3. 启动安卓模拟器，执行 `adb -s emulator-5554 reverse tcp:54321 tcp:54321`。
4. `./scripts/flutter.ps1 run -d emulator-5554 --dart-define-from-file=.tooling/local-phone-defines.json`。日常 Dart 界面修改按 r 热重载。
5. 无配置版本不能完成真实首次连接；调试版可显式进入无资产预览。手机未在本轮重装。
