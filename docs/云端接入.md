# 云端接入验证（T04）

## 范围与结果

用户目前没有 Supabase 云项目。本轮仅启动项目专用本地 Docker Supabase；没有创建云账号、购买套餐或公开发布。

- `supabase test db`：8 个 pgTAP 断言通过，覆盖本人读写、冒用他人 ID 拒绝、不同身份隔离、匿名公开角色无读取授权、私有桶标记。
- `scripts/probe-cloud.ps1`：两个真实匿名 HTTP 会话；验证本人样例读写、伪造写入拒绝、私有 PNG 字节往返、另一用户与公开路径下载拒绝。7 项检查通过。
- 这不是两台物理设备测试，不是互联网免费项目测试，不是家庭共享权限验收。家庭成员关联仍属 M1。
- 测试仅使用合成 1×1 PNG，未上传真实照片；不是用户要求的场景画面生成。

证据：[数据库结果](evidence/m0-db-test.txt)、[HTTP 结果](evidence/m0-local-http.json)。报告不记录会话或服务端密钥。

## 准备免费测试项目后的配置

1. 选择免费项目和区域（Q10 尚待实际网络测试），启用 anonymous sign-ins。
2. 将 `supabase/migrations/202609170001_m0_probe.sql` 应用到专用测试项目；本轮未执行远端迁移。
3. 通过本地忽略的 JSON 配置提供 SUPABASE_URL 和 SUPABASE_ANON_KEY，值仅为 publishable/anon 公钥，绝不能使用 service_role 或 secret key。
4. `./scripts/flutter.ps1 run --dart-define-from-file=.env.test.json -d <设备>`。
5. 猫窝 → 设置 → 验证连接与私有样例文件。无配置时显示未配置，不能误报成功。首次探针连接自动创建独立匿名身份并复用会话，无注册登录页；正式首开接入在 M1。
6. Android 与 iPhone 分别执行 integration_test/cloud_probe_test.dart，并记录实际网络、时间、结果及第二设备权限检查。

私有样例位于 m0_probe_notes 和 m0-probe-private，与正式家庭/钱包分开。匿名用户属于 authenticated 角色，RLS 从 auth.uid() 判断身份。[匿名身份](https://supabase.com/docs/guides/auth/auth-anonymous)、[存储权限](https://supabase.com/docs/guides/storage/security/access-control)。

## 一加连接本机后端（2026-09-21）

一加 Ace 3（PJE110，Android 16）通过 ADB reverse tcp:54321 tcp:54321 连接 Windows Docker Supabase。integration_test/cloud_probe_test.dart 实际执行 1/1 通过：匿名会话可用、样例行写入后回读一致、私有合成 PNG 字节往返一致，同一进程再次连接身份不变。证据：evidence/m0-oneplus-local-cloud.txt。

配置存放在忽略目录 .tooling/local-phone-defines.json，只传入本机 URL 和 anon 公钥。运行命令：`./scripts/flutter.ps1 test integration_test/cloud_probe_test.dart -d 119bad33 --dart-define-from-file=.tooling/local-phone-defines.json --no-pub`。手机重新连接 USB 后需要重新设置 reverse。

第一次运行停在 ADB 安装，主动结束卡住的安装进程后采用保留数据的非流式安装成功，随后完整重试通过。首次失败日志保留在 evidence/m0-oneplus-local-cloud-install-failure.txt，不计为连接测试通过。

本测试没有验证跨进程身份恢复、第二台物理设备、iPhone、远端免费项目网络、家庭共享或免费云暂停恢复。不能用本地测试替代这些验收。

## 本机网关中断恢复（2026-09-21）

`scripts/test-local-reconnect.ps1` 在专用本地 Docker 项目建立匿名会话并写入唯一标记，停止 supabase_kong_CatLibrary 后确认 HTTP 请求失败，再恢复同一网关。原会话身份和已保存行均保持一致，3 项检查通过；finally 确保重启网关。证据：evidence/m0-local-reconnect.json。

该测试未暂停数据库、未模拟免费云平台自动休眠，也未覆盖令牌过期、移动端离线重连或货币补结算。Q10 的真实免费项目可用性和暂停后业务规则仍待实际条件及用户确认。

## 模拟器进程重启身份复用（2026-09-21）

`scripts/test-emulator-cloud-reopen.cjs emulator-5554` 在普通应用设置页连接本机 Supabase 并完成私有样例往返，然后 am force-stop、重开，再次连接。两次返回同一匿名用户 ID，往返均成功。证据：evidence/m0-emulator-cloud-reopen.json。测试使用正常持久化会话，不用重建测试应用冒充冷启动。

当前电脑模拟器使用 .tooling/local-phone-defines.json 中的本机配置，通过 USB/ADB reverse 54321 访问本机；一加普通原型配置保持原样。该配置与数据仅供本地探针，不是正式云接入。
