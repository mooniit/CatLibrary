# 界面设计

## 当前首页与房屋

2026-10-07最终预览方案：用户撤回纯透明和固定深灰蓝底色，恢复跟随主题，白天白色、夜晚深色；面板使用主题surface的96%不透明底色，卡片用surfaceContainerLow及细边线。沿用首页同一房间，未预览时保持放大视口；每次开始预览或选中布置物品时，以权威素材矩形将目标聚焦到上半屏、分类栏之上，大物件及房屋统一等比适配，不拉伸单件。拖动期间视角固定，结束后若物品超出可见区再重新聚焦；转向/挂位变化重新适配。取消清除聚焦，关闭恢复首页原视角。旋转/取消可见圆圈22逻辑像素、触摸目标48逻辑像素，圆圈贴住物品左下/右上角，触摸留白向物品外侧延伸，操作层浮于列表之上。无投影、素材或占格变化。

首页仅使用 `room-standard-v1`：真实正方形地板、8×8 等大格、固定平行投影与 1.5 倍墙高。结构与位置以 [唯一标准](../design/room-structure-2026-10-05/STANDARD.md) 和 `geometry.mjs` 为准。月轨 v5 的独立家具、窗框、画框、墙地构件在同一原生 Flame 场景内组合，接入及制作规则见 [原生月轨说明](plans/room-redesign-2026-10-05/NATIVE-LUNAR.md)。旧房屋结构、素材和备用渲染已删除。

顶部为喵喵币、鹰镑、宝石三张独立余额卡片。点击喵喵币弹窗选择宝石或鹰镑，输入正整数数量，显示按1:5获得的喵喵币。右上菜单依次提供猫咪管理、商店、布置、相册、设置；房间可平移、缩放和复位。

2026-10-07手绘方案覆盖此前界面：商店/编辑只展开首页下方的面板，不替换首页或另开页面；复用Flame场景和GameWidget状态，三张余额卡及右上菜单位置保持。当前小窝移至上方，其下为含All的分类栏，再下方每排四件家具；无筛选、排序和底部分类。关闭恢复首页原平移/缩放。三套36款正式喵喵币价格，每家庭每款1件，卡片0/1或1/1，已拥有不可重购。详情完整图、拥有数、试摆、购买及购买人，明确允许多件才显示数量。商店每次仅在当前布局叠加一件半透明家具；切换商品替换该预览，原家具保持显示。试摆可拖动/吸附/转向，不写库存或草稿。

“布置”入口仅在右上菜单的商店下方，商店面板内没有布置入口。编辑采用相同分类栏/上方小窝/下方四列网格，仅展示实际已拥有SKU，标记已摆与库存；多实例商品先选实际实例，被遮挡家具仍可从卡片选中。进入前核对待请求、读取最新版本并获取120秒编辑权，前台30秒续期。地面家具拖动吸附、占格填色；冲突提示理由，单品确认/取消只改草稿，收起/换款共用校验。窗、画、地毯、墙地仍用固定位置，画芯可选。“保存到家庭”才提交，断网冻结并保留草稿/请求，重连先核对。正常退出释放编辑权并保留草稿。

同日图标化与聚合调整：分类仅All和五类图标，一排完整显示：家具（书柜/书桌/椅子）、猫用（猫爬架/猫窝）、装饰（地毯/画框）、窗景（窗户）、装修（墙面/地板）；商店与布置共用映射，不修改商品kind及其占格/类别限制。类别名称在长按提示和无障碍标签中提供。商品卡以素材图为主体，仅留拥有数/上限及爪印币价，名称和摆放数量解释移至提示或详情；已拥有显示勾号。商店旋转按钮在透明物品左下角、取消在右上角，跟随拖动和转向，用权威素材注册矩形定位，边缘保持可点且避让首页菜单；点击透明物品直接进入商品详情，没有独立详情按钮或底部旋转/取消栏。固定挂位物品不提供自由旋转，仍保留挂位选择。布置的收起、换款、确认、取消、重连、查看、重新开始及保存用图标，触摸目标至少44逻辑像素，保留明确提示。隐藏日常编辑说明和常驻技术版本行，版本在云图标提示中查看；购买/保存结果、断网与冲突仍明确显示。颜色沿用白色#FFFFFF、浅灰#EEF1F4、雾蓝#7186A0、夜底#151A24、夜蓝#9CB2CD；沿用项目Material字体，不引入字体或依赖。小窝是视觉主体，商品网格不加额外装饰和重边框。

另一成员活跃首页检测版本变化后提示手动刷新；重进自动读最新，离线可读确认缓存。继续使用白色简约/雾蓝夜晚主题。最新界面见原生模拟器`evidence/m5-native-*.png`；旧M5-prototype保留历史参考。初始空库存无赠送，旧本机偏好不能转换资产；最新规则见[商品与编辑方案](plans/M5-商品与编辑方案.md)。

墙面分别投影；日间淡月与夜间星月随应用主题切换。两窗取景保持同一月相，不镜像天空内容。画作保持原作比例，默认猫爪星空及戴珍珠耳环的猫。家具第二朝向沿用已确认的镜像方式。猫咪具体造型和动画留待后续；猫咪管理、家庭数据及领养规则继续沿用。

## 其他页面

底部四页导航保持猫窝、任务板、阅读、自习。任务板沿用常规任务计时、照片与完成确认；自习沿用计时、倒计时、常用计时器、记录及结算。阅读页目前显示筹备状态。真实钱包、家庭、修缮和主题设置继续沿用既有功能。

手机完整构建必须携带原服务配置；未连接服务的交互预览只有简化页，不作为真实功能验收依据。构建方式见原生月轨说明。
