# 界面设计（非视觉定稿）

## 2026-09-29：首页实施方案

用户已认可最后一版「收小地板、保留高墙」[概念图](../design/art/home-approved.png)，授权先写方案再实施。[原始风格参考图](../design/art/room-style-reference-03.png)和两只猫的角色设定图均保存在 `design/art`。以下作为本轮实现依据，替代此前仅讨论、不编码的阶段约束。

### 画面与默认构图

- 手机竖屏，猫窝占据底部导航以上的整块可用区域，不再放在滚动列表的小卡片里，也不重复显示页面标题。
- 固定斜俯视 2.5D：暖木地板、浅色两面高墙、细描边、柔和插画质感；地板比上一版铺满屏幕的方案收小，默认构图适当露出前沿。房间左右可以适度超出视口。
- 基础房间与陈设分层：房间壳体、书柜、软猫窝、三花猫、蓝眸长毛猫。左后方书柜、右后方猫窝为初始视觉锚点；猫咪保持小比例，不再作为大幅肖像。
- 本轮沿用已有本机布置草稿功能，将旧桌椅占位换为书柜和猫窝。素材锚点以地面接触位置为准，按地面纵深排序，避免浮空和错误遮挡。网格仍是布置实验尺度，不代表房间真实米数。
- 亮暗主题只改变外围背景和控件颜色，房间素材与照明保持一致。

### 界面层级与操作

- 顶部：紧凑的半透明钱包栏，显示个人喵喵币、鹰镑、宝石及真实数量；未连接显示破折号与预览状态，不显示概念图的演示金额。欠款保留负号，并提供明确文字说明。
- 点击钱包打开现有兑换入口；不新增经济规则。
- 右上：设置图标，叠放在场景上。家庭与邀请移入设置，保留原功能可达性。
- 下部：布置、猫咪管理、商店、相册四个简洁线条图标，悬浮在地板画面上，使用轻薄半透明圆形底，不显示文字。图标约 22～24 逻辑像素，触控范围至少 48×48，保留工具提示与无障碍名称。
- 最底部：沿用猫窝、任务板、阅读、自习的仅图标导航。钱包、设置、功能按钮和导航均固定在屏幕上，不随房间平移。
- 普通查看可拖动房间、双指缩放；有限平移范围防止整间房丢失，提供回到初始视角的操作。普通拖动不改变家具位置。
- 布置时选择书柜或猫窝，拖动所选物件或用已有方向键微调；保存预览/取消及离开草稿确认继续有效。保存只保留当前运行的本机预览，不宣称已云端保存。
- 修缮提示仍可见、可滚动阅读，家庭代扣提醒继续沿用；商店和相册维持已有入口/空状态，不伪造商品与旅行记录。

### 猫咪数据与素材

- 未连接的交互预览可展示两只示例猫，明确标注预览；连接后的首页按家庭实际领养数据展示，最多四只，空家庭不自动放入两只猫。
- 从猫咪管理或家庭设置返回、应用恢复时刷新猫咪；失败保留本次已加载内容并提供重试，不用示例猫冒充真实领养。
- 三花猫正式替代黑猫的显示名称和素材。既有服务端预设键 `black_short` 本轮保留，映射为三花猫，避免改变已领养记录及两种外观的名额规则；`light_long` 显示为蓝眸长毛猫。
- 图片只包含场景/物件，不烘焙按钮、余额、文字或猫咪名；素材随项目保存。猫咪动作、正式云端家具编辑和旅行实现不属于本轮首页视觉接入。
- 本轮使用内置图像生成工具按已确认概念图绘制透明的空房间壳体 `assets/images/room/shell.png`；再按房间画风与两张角色设定图生成书柜、猫窝、三花猫、蓝眸长毛猫四象限图集 `assets/images/room/objects.png`。书柜、猫窝和猫咪按图集区域独立绘制与排序，UI 由 Flutter 绘制。素材是本轮游戏原型资源，后续动作素材仍按角色标准设定图细化。

### 实施与验收顺序

1. 保存选定概念图，制作房间层与透明物件素材，接入 Flame 场景及地面锚点。
2. 将首页改为场景与悬浮控件叠层，接回钱包、猫咪、设置、家庭、修缮和原有导航。
3. 验证：拖动只改变视角且按钮不动；缩放/复位正常；家具草稿保存和取消正确；真实空家庭不出现示例猫；按钮可达且不显示文字；窄屏及亮暗主题无布局溢出。
4. 运行相关 Flutter 测试与静态分析，在浏览器实际检查竖屏画面及操作，并记录截图。平台原有计时与结算规则不变。

## 2026-09-29：首页设计方向

- 用户重新启动视觉设计，先采用本轮「03」参考图的紧凑微缩房间风格：固定斜俯视 2.5D、浅色两面墙、暖木地板、柔和描边及插画质感。
- 首页采用竖屏；外围界面沿用已确认的白灰/蓝灰与深灰/雾蓝主题，不用绿色作为界面强调色，主题切换不改变场景内容。
- 三花猫正式替代黑猫，与蓝眸长毛猫组成两套预设；角色外观以 `design/art` 中的角色标准设定图为准，详见需求文档 6.2。
- 本轮先制作首页视觉方案与概念图，不修改界面代码。概念图中的余额为演示值，猫咪同时出现不代表首次启动自动领养。
- 顶部以紧凑单行显示个人喵喵币、鹰镑、宝石及数量；图标简化，猫咪维持较小比例，避免压过房间主体。
- 用户后续确认：增加房间在竖屏中的占位，适当加宽地板面积并增高墙壁；房间可通过拖动画面自由平移查看，不要求默认视野完整容纳房间所有边缘。具体比例及平移边界通过原型细化。
- 设置位于右上，布置、猫咪管理、商店、相册位于下部，均悬浮叠放在猫窝场景之上；按钮固定在屏幕上，不随房间平移，不另占场景外的一块布局区域。四个功能按钮只显示简洁图标，不显示文字；保留足够触控范围及无障碍名称。
- 底部保留猫窝/任务板/阅读/自习四个仅图标导航入口；悬浮功能按钮位于导航栏上方。按钮操作与场景拖动分开响应，普通查看时拖动画面不移动家具。
- 初始陈设暂以参考图中的书柜、软猫窝为构图基础；最终清单、固定/可移动属性、房间尺度及控件位置待确认。

## 当前可操作范围

- 四页底部导航：猫窝、任务板、阅读、自习。
- 猫窝用 Flame 绘制网格、桌椅与两只猫的文字占位；不表现猫咪性格，不宣称真实比例或细节验收。
- 猫窝内商店/相册为空状态入口，设置内有云连接探针。
- 猫咪管理：选择两种外观之一、填写名字、本人试领养；只保留本次内存状态。限制本人重复外观、空名字、重复名；家庭及并发校验不在 M0。
- 布置：选择桌/椅后拖动，或用箭头移动；只修改草稿；“保存预览”保留当前内存布局，“取消”回滚；切换底部页或返回时展示放弃草稿确认。无编辑权、云端保存、双端刷新实现。
- 阅读只显示“阅读功能筹备中”。
- 自习显示真实经过时间和原始日期分段，所有确认只确认探针记录，不发奖励。
