## 查看与运行

```powershell
./scripts/flutter.ps1 test
./scripts/flutter.ps1 analyze
./scripts/flutter.ps1 build web --no-web-resources-cdn
node scripts/preview.cjs
```

打开 http://127.0.0.1:4173，仅绑定本机。无需查看或确认美术。手机接入后使用 `./scripts/flutter.ps1 devices` 取得编号，再 `./scripts/flutter.ps1 run -d <编号>`。

浏览器复验依赖 `.tooling/browser` 下 Playwright Core 1.58.2 和现有 Edge：

```powershell
npm install --prefix .tooling/browser --save-exact playwright-core@1.58.2
node scripts/test-web.cjs
```

```powershell
./.tooling/android-sdk/platform-tools/adb.exe -s emulator-5554 install -r output/android/cat-library-m0-x64-debug.apk
./.tooling/android-sdk/platform-tools/adb.exe -s emulator-5554 shell am start -n com.catlibrary.cat_library_demo/.MainActivity
```
