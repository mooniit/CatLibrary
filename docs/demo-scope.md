# 猫窝视觉与交互演示

本次用户授权：基于提供的三张房屋参考图制作一个可操作示例，验证此前推荐的 Flutter + Flame 路线。

## 范围

- 暖色、非像素、固定斜俯视角的单层书房。窗户、书架属于固定场景。
- 三件可拖动的独立家具素材，一只真实比例的黑猫。
- 家具按地面网格移动、前后遮挡、选择反馈、手动保存和放弃修改。
- 本机保存布局，刷新后恢复。演示使用 shared_preferences；不冒充云端同步或正式 SQLite 业务层。
- 抚摸反馈和猫咪在房间中的简单活动。
- 底部猫窝、任务板、阅读、自习入口；非猫窝页面清楚标为预览，不执行钱包业务。
- 桌面浏览器可打开。保留 Flutter 项目，可继续用于 Android/iOS 开发；本次不声称经过移动真机验证。

## 美术方向

参考前两张图的视角与紧凑空间，第三张图的非像素细节。温暖现实书房，初始布置较少。生成素材不复用原截图中的家具或人物。四个家具/猫咪素材和房间背景独立，以便实际拖动与遮挡。

## 验证

- 网格投影与逆变换、地面边界、保存前不修改已保存布局、取消恢复、存档校验。
- Flutter analyze、Flutter test、Web release build。
- 实际浏览器检查加载、选择与移动家具、保存、刷新、取消、猫咪互动和窄屏。
