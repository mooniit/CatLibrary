# M2 实施记录

更新：2026-09-26。状态：实施中，尚未通过 M2 出口 C06。

## 已实现的独立基础部分

- 正式 AppDatabase 与 M0 探针数据库分离；按身份保存多条自习记录。
- 记录保存开始时间、最后可靠时间、待确认/待同步/已同步状态；毫秒证据不提前作货币取整。
- 同一身份仅一条运行中记录，开始时检查既有时间区间；单次 6 小时上限跨日不重置。
- 冷启动恢复将运行记录改为待确认，不把停机时间补进记录。
- 确认状态与同步队列同事务提交；队列写入失败回滚确认。
- 写入失败停止内存计时，恢复前禁止重新开始或确认。
- UTC+8 日期分段保留毫秒；跨日奖励规则未接入。
- 同步 worker 保留相同记录 ID 重传，收到成功响应后再清队列；提交接口目前通过测试替身验证，未接真实奖励 RPC。

这些新增基础类尚未替换应用里的 M0 TimerProbe；现有安装包不会显示为已完成 M2。

- Flutter 全量测试 35/35 通过（原有 24，新增 11）；flutter analyze 无问题。
